# SillyTavern

LLM Frontend for Power Users.

SillyTavern is a locally installed user interface that allows you to interact with text generation LLMs, image generation engines, and TTS voice models.

## Documentation
For full documentation, visit [docs.sillytavern.app](https://docs.sillytavern.app/).

## Features
- **Multi-Backend Support**: Connect to OpenAI, Claude, Mistral, LM Studio, KoboldAI, and more.
- **World Info**: Create rich lore for your characters.
- **Group Chats**: Have multiple characters interact with each other.
- **Extensions**: TTS, Image Generation, Auto-Summary, and more.

## Installation
SillyTavern requires Node.js 18+.
1. `git clone https://github.com/SillyTavern/SillyTavern.git`
2. `cd SillyTavern`
3. `./start.sh` (or `Start.bat` on Windows)
